# Pong Online

Многопользовательская клиент-серверная реализация игры Pong
Проект разработан с акцентом на сетевое взаимодействие, обмен сообщениями по TCP 
и синхронизацию состояния игры между несколькими клиентами в режиме реального времени

## Основные возможности

- Клиент-серверная архитектура
- TCP Socket API
- Протокол обмена сообщениями JSON
- Многопоточная обработка клиентских подключений
- Создание и управление игровыми комнатами
- Синхронизация игрового состояния в реальном времени
- Обработка подключения и отключения игроков
- Обработка ошибок и сетевых событий

## Технологии

- Python
- Socket API
- TCP/IP
- JSON
- Threading
- PyQt6

## Архитектура

- **Server** — принимает подключения, управляет игровыми комнатами, обрабатывает действия игроков и синхронизирует состояние игры
- **Client** — подключается к серверу, отправляет пользовательские действия и отображает актуальное состояние игры
- **Game Logic** — отдельный модуль с игровой физикой, подсчётом очков и определением победителя

## Запуск приложения

### Установка зависимостей

```bash
pip install PyQt6
```

### Запуск сервера

```bash
python pong_server.py
```

### Запуск клиента

Откройте два терминала и выполните:

```bash
python main.py
```

после подключения создайте игровую комнату или подключитесь к уже существующей
